# Research roadmap

This roadmap distinguishes exploratory conceptual work and synthetic demonstrations from empirical validation. Planned work is not evidence that a framework or finding has been validated.

| Research item | Status | Type |
| --- | --- | --- |
| Score → Evidence → Claim conceptual framework | Working draft | Conceptual work |
| Claim–evidence matrix | Initial illustrative example | Conceptual work |
| Synthetic demonstration: same score, different evidence | Planned | Synthetic demonstration |
| Agreement Isn't Validity | Planned | Conceptual work, with a possible synthetic demonstration |
| Measurement reliability and agent evaluation studies | Exploratory | Future empirical research |

Conceptual work clarifies terms and proposed reasoning. Synthetic demonstrations illustrate how assumptions can affect interpretation using constructed data. Empirical validation requires separately designed studies and should not be inferred from either conceptual notes or synthetic examples.
